# PDFree

Бесплатный редактор и сервис подписи PDF, который работает **целиком в браузере**.
Файл пользователя никогда не уходит на сервер: PDF читается, редактируется и
пересобирается на его же устройстве. Поэтому хостинг стоит ноль — это статический
сайт без бэкенда.

*A free, fully client-side PDF editor and signer. No backend, no uploads, no limits.*

---

## Что умеет

**Редактор** (`#/editor`)
- текст с кириллицей (обычный, с засечками, моноширинный, рукописный), жирный, цвет, размер;
- подпись: нарисовать мышью/пальцем, напечатать рукописным шрифтом или загрузить фото
  (белый фон скана удаляется автоматически, картинка обрезается по чернилам);
- вставка изображений, галочки, рисование от руки, маркер, прямоугольники;
- «Скрыть» (redact) — чёрная плашка; при сохранении предлагается растрировать страницы,
  чтобы текст под плашкой действительно исчез, а не просто закрасился;
- страницы: поворот, удаление, дублирование, миниатюры слева;
- undo/redo, горячие клавиши (V, T, S, I, X, D, H, R, B, Ctrl+Z, Ctrl+S), зум.

Поставленный объект сразу выделен: его можно двигать и менять размер, не переключаясь
на «Выбор». Инструменты-фигуры (кисть, маркер, прямоугольник, «скрыть») при этом
продолжают рисовать поверх остальных объектов — они отдают указатель только тому
объекту, который выделен. Росчерк кисти захватывается за саму линию, а не за
прямоугольник вокруг неё.

**Инструменты** (`#/tools`)
объединить, разделить (диапазон или по одной странице), повернуть, PDF → PNG/JPG,
изображения → PDF, сжать, водяной знак, нумерация страниц, извлечь текст.

Интерфейс на русском и английском, светлая и тёмная тема.

## Запуск локально

Нужен любой статический сервер (из-за web worker'а pdf.js файл `index.html`
не будет работать по `file://`).

```bash
python serve.py
```

Затем откройте http://127.0.0.1:8787

`serve.py` — обычная раздача статики, но с отключённым кэшем, чтобы правки в
js/css было видно сразу после F5. Для простого просмотра подойдёт и
`python -m http.server 8787`.

## Публикация (бесплатно)

Проект — обычные статические файлы, поэтому подойдёт любой из вариантов:

- **GitHub Pages** — залейте репозиторий, включите Pages для ветки `main`, папка `/`.
- **Cloudflare Pages** — «Direct upload», перетащите папку целиком.
- **Netlify Drop** — перетащите папку на https://app.netlify.com/drop.

Сборка не нужна: ни npm, ни Node.js в рантайме не используются.

### Один файл вместо папки

```bash
python build.py
```

Кладёт в `dist/pdfree.html` весь сайт целиком — стили, скрипты, библиотеки,
шрифты и worker pdf.js внутри одного файла (~4,6 МБ). Его можно отправить письмом,
положить на флешку или открыть двойным кликом с диска: он работает без сервера и
без интернета.

`python build.py --fragment --cdn` собирает вариант для площадок, которые сами
оборачивают содержимое в `<html><body>` и не принимают библиотеки внутри страницы:
код библиотек подключается с jsDelivr, шрифты и worker остаются внутри.

## Структура

```
index.html            разметка всех экранов
css/style.css         тема, компоненты, адаптив
js/i18n.js            словари RU/EN + t()
js/core.js            загрузка PDF, рендер, геометрия страниц, шрифты, скачивание
js/editor.js          слой аннотаций, модалка подписи, экспорт PDF
js/tools.js           отдельные инструменты (реестр TOOLS)
js/app.js             роутинг, карточки инструментов, форма опций
vendor/               pdf.js, pdf-lib, fontkit, JSZip (локальные копии)
assets/fonts/         Roboto (кириллица) и Caveat (рукописный шрифт подписи)
test/sample.pdf       тестовый файл: 2 страницы, вторая с /Rotate 90
serve.py              локальный сервер для разработки (без кэширования)
```

### Как устроены координаты

Аннотации хранятся в «визуальных» координатах: начало — левый верхний угол страницы
так, как её видит пользователь, ось Y вниз, единицы — пункты PDF. У страницы может
быть свой `/Rotate`, поэтому визуальная система координат не совпадает с системой
pdf-lib. Пересчёт делают `Core.mapPoint()` и `Core.boxAnchor()` в `js/core.js`.

### Как добавить инструмент

В `js/tools.js` добавьте запись в `TOOLS`:

```js
myTool: {
  icon: '✨', accept: 'application/pdf',
  options: [{ id: 'foo', type: 'text', label: 'o.text' }],
  async run(files, opts, progress) {
    return [{ name: 'result.pdf', data: bytes }];
  }
}
```

Добавьте id в `TOOL_ORDER` и ключи `tools.myTool.t` / `tools.myTool.d` в оба словаря
`js/i18n.js`. Форму опций и скачивание результата возьмёт на себя `js/app.js`.

## Ограничения (честно)

- **Подпись здесь — простая электронная подпись** (изображение в документе).
  Квалифицированная подпись с криптосертификатом требует аккредитованного удостоверяющего
  центра и здесь не реализуется.
- **PDF с паролем** не открываются — сначала снимите защиту.
- **Сжатие** работает растеризацией: для сканов даёт большой выигрыш, а векторный
  текстовый PDF может даже вырасти в размере (инструмент показывает обе величины) и
  перестанет быть текстовым.
- **Редактирование исходного текста документа** не поддерживается: как и в большинстве
  бесплатных сервисов, правки накладываются поверх страницы.
- Большие файлы (сотни страниц) обрабатываются в памяти вкладки — на слабых устройствах
  это заметно.
